## Refreshing this inventory

To refresh the first table, page through
`https://crates.io/api/v1/crates?user_id=6738&per_page=100` (6738 is the
`sunshowers` user ID).

To refresh the Oxide tables, there is no shortcut: crates.io has no Oxide team
and its API cannot search by repository. Stream
`https://static.crates.io/db-dump.tar.gz` (about 2 GB), extract only
`data/crates.csv`, `data/crate_owners.csv`, and `data/users.csv`, and filter
`crates.csv` for a `repository` matching `github.com/oxidecomputer`. Then list
the other crates owned by the same accounts to catch crates with an empty or
non-Oxide `repository` field.

Limitations of this method:

- A crate published by an Oxide engineer from a personal repository, with no
  mention of Oxide, does not appear here unless it was added by hand.
- Most Oxide code (Omicron, Crucible, Propolis, Hubris, and their internal
  libraries such as `slog-error-chain`) is not published to crates.io at all and
  is consumed through git dependencies. It is out of scope for this list.
